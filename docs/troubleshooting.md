\# Troubleshooting



\## Permission denied



Make a script executable:



&#x20;   chmod +x scripts/system-info.sh



\## Script not found



Run the script from the repository root:



&#x20;   ./scripts/system-info.sh



\## Invalid disk threshold



The disk check script accepts values from 1 to 100:



&#x20;   ./scripts/check-disk.sh 80



\## Missing Linux utilities



Install the required utilities using your distribution's package manager.
